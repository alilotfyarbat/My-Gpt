# My-GPT | LocalAI-WebUI

هوش مصنوعی محلی با استفاده از **Ollama** و رابط کاربری تحت وب با **Python (Flask)**.

رابط کاربری ساده، کاربرپسند و قدرتمند برای مدیریت و تعامل با مدل‌های هوش مصنوعی محلی — بدون نیاز به اینترنت، بدون ارسال داده به سرور خارجی، با پشتیبانی کامل از **فارسی (RTL)** و **انگلیسی (LTR)**.

---

## 🎛 دو نسخه برنامه

این پروژه با **دو نسخه** ارائه می‌شود که هر دو از یک رابط کاربری مشترک استفاده می‌کنند و کنار هم در ریشه پروژه قرار دارند:

| فایل | نسخه | مناسب برای |
|------|------|------------|
| `app1.py` | **نسخه سفارشی (Custom)** | کاربرانی که پاسخ‌های شخصی‌سازی‌شده و فیلتر نام برندها می‌خواهند |
| `app2.py` | **نسخه استاندارد (Standard)** | کاربرانی که پاسخ خام و بدون تغییر مدل‌ها را می‌خواهند |

> 💡 **چرا دو فایل جداگانه؟** چون دو نسخه رفتار متفاوتی دارند و به‌جای تنظیمات پیچیده، هر نسخه یک فایل مستقل و ساده است — کافیست همان یکی را اجرا کنید. (شماره‌گذاری `app1` و `app2` فقط برای جدا بودن دو نسخه است و اولویتی به آن‌ها معنا نمی‌دهد.)

## 🧠 نسخه سفارشی — `app1.py`

این نسخه علاوه بر کار اصلی، دو قابلیت اضافه دارد:

### ۱. پاسخ سفارشی به سؤالات خاص
اگر در چت بنویسید «اسم تو چیه؟» یا «سازنده تو کیه؟»، به‌جای پاسخ مدل، پاسخ از پیش تعیین‌شده نمایش داده می‌شود:
- «اسم تو چیه» ← **«اسم من [علی] است.»**
- «سازنده تو کیه» ← **«من توسط [علی] ساخته شدم.»**

این پاسخ‌ها در ابتدای تابع `ask()` تعریف شده‌اند و می‌توانید سؤال‌ها و جواب‌های دلخواه خود را اضافه کنید.

### ۲. جایگزینی نام برندها در پاسخ‌ها
قبل از نمایش پاسخ، نام مدل‌ها و شرکت‌ها به‌صورت خودکار (بدون توجه به بزرگ/کوچک بودن حروف) جایگزین می‌شود:

| در متن پاسخ | نمایش داده می‌شود |
|--------------|-------------------|
| Qwen / Gemma / DeepSeek | ALI |
| Phi / Luna / Nova / LLaMA | Ali |
| Meta / Alibaba / Google / Microsoft | Ali CO |
| گوگل | کمپانی علی |

این لیست در تابع `process_response()` در دیکشنری `replacements` قرار دارد و آزادانه قابل تغییر است.

## 🧠 نسخه استاندارد — `app2.py`

نسخه پایه پروژه با حداقل کد ممکن: هیچ پاسخ سفارشی یا فیلتری ندارد و **پاسخ خام مدل** را مستقیم و بدون تغییر نمایش می‌دهد. اگر پاسخ واقعی مدل‌ها را می‌خواهید یا می‌خواهید پایه‌ای برای توسعه خودتان داشته باشید، از این نسخه استفاده کنید.

## ✨ ویژگی‌های کلیدی

- **پردازش کاملاً محلی** — تمام پردازش‌ها با Ollama روی سیستم خودتان انجام می‌شود
- **مقایسه مدل‌ها** — انتخاب همزمان چند مدل و مشاهده پاسخ‌ها در کنار هم
- **رابط کاربری واکنش‌گرا** — با حالت تیره (Dark Mode) و پشتیبانی فارسی/انگلیسی

## 🚀 نصب و اجرا

### پیش‌نیازها
1. **Python 3.8 یا بالاتر** ← [دانلود](https://www.python.org/downloads/)
2. **Ollama** ← [دانلود](https://ollama.com/download)
3. مدل‌های نصب‌شده در Ollama، مثلاً:
   ```bash
   ollama run qwen2.5:1.5b
   ollama run deepseek-r1:1.5b
   ```

### مراحل اجرا
```bash
# ۱. نصب کتابخانه‌های مورد نیاز (فقط یک بار)
pip install -r requirements.txt

# ۲. اجرای نسخه سفارشی
python app1.py

# یا اجرای نسخه استاندارد
python app2.py
```

سپس در مرورگر باز کنید: **http://127.0.0.1:5000**

> 💡 قبل از اجرا مطمئن شوید Ollama روی سیستم شما در حال اجراست (پورت پیش‌فرض `11434`).

### نحوه استفاده
1. پرامپت خود را در فیلد پیام وارد کنید
2. مدل‌های مورد نظر را از لیست انتخاب کنید (برای مقایسه، چند مدل را همزمان انتخاب کنید)
3. دکمه **Enter** را بزنید و منتظر پاسخ بمانید
